## TL;DR

Reading a geometric property (`offsetHeight`, `getBoundingClientRect()`) after invalidating styles forces the engine to run Layout synchronously mid-script instead of deferring it to the end of the frame.

## Under the Hood

1. A DOM write (`el.style.width = '100px'`) sets a `NeedsLayout` dirty flag on the `LayoutObject` and its ancestors in the [Browser Rendering Pipeline](/concepts/browser-rendering-pipeline).
2. Normally, geometry computation is deferred until `Update the Rendering` at the end of the [Event Loop](/concepts/event-loop-tasks-microtasks) frame.
3. Any box metric read (`offsetTop`, `clientWidth`, `getComputedStyle(el).width`) forces a synchronous `Document::UpdateStyleAndLayoutTree()` to return an up-to-date value.

```js
// Bad: N forced synchronous layouts in one loop
for (const card of cards) {
  const w = card.offsetWidth; // Read -> forces Layout
  card.style.width = `${w + 10}px`; // Write -> dirties Layout
}

// Good: batch all geometric reads before any DOM write
const widths = cards.map((card) => card.offsetWidth);
cards.forEach((card, i) => {
  card.style.width = `${widths[i] + 10}px`;
});
```

## Problem Genealogy

- **2005 (jQuery Animations)**: `.each()` loops reading `.height()` then writing `.css('height', ...)` across entire lists, guaranteeing 10 FPS on a 200-row table.
- **2013 (FastDOM)**: Libraries separating read and write queues around `requestAnimationFrame` using [rAF Coalescing](/concepts/debounce-throttle-raf-coalescing).
- **2020+ (`ResizeObserver` & `content-visibility`)**: Asynchronous dimension observation without forced synchronous reads.

## Production Pitfalls

- **Virtualized Lists & Grids**: Measuring each row after insertion causes O(N) layouts and drops frame rates below 15 FPS.
- **Third-Party Analytics**: A tracker calling `getBoundingClientRect()` right after a framework commit triggers a full-page reflow on someone else's dime.
- **When not to use manual read/write batching**: For resize observation, replace manual metric reads with [CSS Container Queries](/concepts/css-container-queries) or `ResizeObserver` instead of maintaining custom read queues.
