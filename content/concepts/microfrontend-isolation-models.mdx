## TL;DR

Micro-frontends trade isolation strength against memory and UX friction. [Shadow DOM](/concepts/shadow-dom-encapsulation) scopes CSS inside one browsing context, [ES Modules](/concepts/es-modules-live-bindings) import maps deduplicate shared runtimes, and `<iframe>` enforces full origin and JS heap boundaries.

## Under the Hood

Each isolation primitive enforces a different boundary inside the browser's renderer process.

1. **Module Federation & Import Maps**: Shares a single `window`, `document`, and JS heap; a central dependency resolver negotiates singleton versions (e.g., `react@19`) so remotes do not download duplicate 45 KB runtimes.
2. **Shadow DOM + Proxy Sandbox**: `attachShadow({ mode: 'open' })` blocks outer CSS selectors from bleeding inward, while a `Proxy(window)` sandbox intercepts global property writes per sub-app.
3. **Cross-Origin `<iframe>`**: Allocates an isolated browsing context (and often a separate OS site-isolation process via COOP/COEP), communicating strictly over `postMessage()` structured clones.

```html
<script type="importmap">
  {
    "imports": {
      "react": "https://cdn.example.com/react@19/index.js",
      "@billing/widget": "https://billing.example.com/widget.js"
    }
  }
</script>
<billing-shell></billing-shell>
```

## Problem Genealogy

- **2016 (Iframes & Portal Shells)**: Guaranteed fault and CSS isolation, but broke URL deep-linking, accessibility focus, and modal overlays at iframe viewport edges.
- **2020 (Webpack Module Federation)**: Shared singletons dynamically across independently deployed builds, risking runtime crashes when teams drifted on incompatible peer dependencies.
- **2024 (Import Maps + Shadow DOM)**: Native browser module resolution paired with declarative Shadow DOM eliminated bundler-specific runtime loaders.

## Production Pitfalls

- **Dual-Framework Heap Bloat**: Loading both React 18 and React 19 remotes without singleton version negotiation duplicates event delegation listeners on `document` and doubles baseline JS memory.
- **Portal Escape Through Shadow Boundaries**: Rendering a modal via `document.body.appendChild` breaks out of the Shadow DOM root and loses all scoped component styles.
- **When not to use micro-frontends**: Never split an application owned by fewer than 3 independent teams into runtime micro-frontends; cross-team version skew, duplicate shared chunks, and `postMessage` serialization latency cost more than a modular monorepo.
