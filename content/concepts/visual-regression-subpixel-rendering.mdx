## TL;DR

Visual snapshot tests flake across developer laptops and Linux CI because macOS CoreText, Windows DirectWrite, and Linux FreeType rasterize [subpixel](/concepts/device-pixel-ratio-subpixel) glyph outlines differently. Pinning a containerized Chromium rasterizer, awaiting [font loading](/concepts/font-loading-cls), and disabling animations yields byte-stable screenshots.

## Under the Hood

Blink's Skia backend delegates font shaping and glyph rasterization to the host OS text stack unless constrained by a uniform container environment.

1. **OS Font Hinting Divergence**: macOS CoreText applies grayscale anti-aliasing at `devicePixelRatio: 2`, whereas Linux FreeType applies different hinting and LCD subpixel filtering at `devicePixelRatio: 1`.
2. **Font & Image Readiness**: Capturing a frame before `await document.fonts.ready` or image decode causes FOUT fallback diffs across runs.
3. **Animation & Caret Freezing**: Passing `animations: 'disabled'` and `reducedMotion: 'reduce'` ([prefers-reduced-motion](/concepts/user-preference-media-queries)) fast-forwards CSS transitions to their final keyframe and hides blinking text carets.

```ts
await page.emulateMedia({ reducedMotion: 'reduce' });
await page.evaluate(() => document.fonts.ready);

await expect(page.getByTestId('pricing-card')).toHaveScreenshot({
  animations: 'disabled',
  maxDiffPixelRatio: 0.005,
});
```

## Problem Genealogy

- **2014 (PhantomJS / Host-OS Screenshots)**: Teams committed macOS baselines that failed 100% of Linux CI builds due to 1px-2px font baseline shifts.
- **2018 (High `threshold: 0.2` Workarounds)**: Raising pixel tolerance to silence font noise let real 2px border regressions and broken icons pass undetected.
- **2022 (Pinned Docker Chromium + `animations: 'disabled'`)**: Standardizing on identical Linux container images cut false-positive visual diffs below 0.5% while preserving strict pixel thresholds.

## Production Pitfalls

- **Non-Deterministic `<video>` and WebGL Frames**: Hardware-accelerated `<canvas>` and `<video>` elements decode at variable frame timestamps and GPU driver tolerances across runs.
- **Dynamic Timestamps & Avatars**: Unmasked relative times (`2 minutes ago`) or external CDN images trigger constant pixel churn unless stubbed or passed in `mask: []`.
- **When not to use Pixel-Diff Snapshots**: Never run strict pixel-diff assertions on WebGL scenes, live video streams, or unpinned host-OS browsers across macOS and Linux; use structural DOM/ARIA assertions or pinned container rasterizers instead.
