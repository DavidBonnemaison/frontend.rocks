## TL;DR

The `popover` attribute promotes a non-modal element into the Top Layer via `popovertarget`. The browser handles outside clicks (*light-dismiss*), the `Escape` key, and mutual exclusivity between `auto` popovers natively.

## Under the Hood

1. An element with `popover="auto"` enters the Top Layer (shared with the [Native `<dialog>` Element](/concepts/native-dialog-element)) when its `popovertarget` button is clicked, without blocking background interaction.
2. The engine maintains an internal stack of open `auto` popovers: opening a second popover closes the previous one automatically (unless it is a direct ancestor).
3. Any `pointerdown` outside the popover or pressing `Escape` triggers native *light-dismiss* without fragile [DOM Event Propagation](/concepts/dom-event-propagation) hacks.

```html
<button popovertarget="actions-menu">Actions</button>

<div id="actions-menu" popover="auto">
  <button type="button">Duplicate</button>
  <button type="button">Archive</button>
</div>
```

## Problem Genealogy

- **2014 (`document.addEventListener('click')`)**: Shipping 40 KB of JavaScript just to close a dropdown when the user clicks outside, and watching it break whenever a third-party widget calls `stopPropagation()`.
- **2020 (Popper / Floating UI wrappers)**: Manual portal mounting and outside-click dismissal hooks.
- **2024+ (Popover API Baseline)**: Top Layer lifecycle and declarative dismissal directly in HTML.

## Production Pitfalls

- **Confusing `auto` and `manual`**: A notification toast using `popover="auto"` vanishes as soon as the user clicks anywhere; use `popover="manual"` for persistent toasts.
- **Anchor positioning**: `popover` does not automatically position the surface next to its trigger; pair it with CSS Anchor Positioning or lightweight coordinate math.
- **When not to use `popover`**: For a critical page-blocking modal (such as a destructive confirmation), use `<dialog>.showModal()`. For arrow-key navigation across menu items inside a popover, pair it with [Roving Tabindex](/concepts/roving-tabindex-focus-order).
