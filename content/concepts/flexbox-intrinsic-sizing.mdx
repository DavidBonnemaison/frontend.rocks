## TL;DR

Flex items do not shrink below their `min-content` width by default because `min-width: auto` acts as a hard floor. Setting `min-width: 0` (or `overflow: hidden`) removes that floor so `flex-shrink` and `text-overflow: ellipsis` actually work.

## Under the Hood

Flexbox runs a two-pass negotiation: first it measures every child's intrinsic content size, then it distributes surplus or deficit space along the main axis.

1. **Hypothetical Base Size**: The engine resolves `flex-basis` (falling back to `width`/`height`, then `max-content`).
2. **The `min-width: auto` Clamp**: Unless the item is a scroll container, its minimum main size defaults to its `min-content` width, blocking `flex-shrink: 1` from crushing text or images.
3. **Space Distribution**: Free space is allocated proportionally by `flex-grow` or subtracted by `flex-shrink * flex-basis`.

```css
/* Without min-width: 0, long tokens push the flex row off-screen */
.sidebar-label {
  flex: 1 1 0%;
  min-width: 0;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

Compare this single-axis negotiation with [CSS Grid Track Sizing](/concepts/css-grid-track-sizing), where tracks also clamp at `minmax(auto, 1fr)` unless written as `minmax(0, 1fr)`, and [Block Formatting Context](/concepts/block-formatting-context) flow.

## Problem Genealogy

- **2012–2014**: Early Flexbox drafts used `min-width: 0` by default, causing text to overlap or vanish inside narrow columns; CSSWG changed the default to `min-width: auto`.
- **2015+**: `min-width: 0` became the universal escape hatch for truncating text and embedding scrollable panes inside flex layouts.

## Production Pitfalls

- **Truncated text refuses to ellipsis**: `text-overflow: ellipsis` inside a flex child fails silently until `min-width: 0` is set on every intermediate flex item up the chain.
- **Misunderstanding `flex: 1` vs `flex: auto`**: `flex: 1` sets `flex-basis: 0%` (equal columns); `flex: auto` sets `flex-basis: auto` (wider content gets a wider column).
- **When not to use Flexbox**: Avoid Flexbox for strict two-dimensional card alignments where row tracks must line up across columns; use CSS Grid instead.
